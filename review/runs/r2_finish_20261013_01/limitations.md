# R2 기술 해석 한계

- 비중의 분모는 기록된 상호작용이다. 전체 교통량 노출, 사고확률, 법적 위반 또는 정책 우선순위가 아니다.
- A는 기존 비음수 이벤트 집계를 보존한다. C/D는 시나리오와 순서 있는 객체쌍별 첫 이벤트를 사용한 민감도이며, 복수 conflict point의 기하학적 동등성은 독립 검증하지 않았다. 반복 기록을 오류로 삭제하지 않았다.
- 날짜 bootstrap은 B=200, seed=20261012의 탐색 민감도이다. 공통 날짜 추출을 공유하지만 날짜의 독립성과 모집단 일반화를 보장하지 않는다. 순위 분위수는 일반화 95% 신뢰구간이 아니다.
- 신호 상태는 양 역할 각각의 conflict-area 진입시각 기준이다. 동시에 발생한 두 신호나 정지선 신호가 아니다. 이벤트 네 시각만 이동하며 신호 clock과 PET는 고정한다. ±1·±2초는 스트레스 조건이며 실제 오차분포가 아니다.
- 2025-06-05~11 구간은 파일상 coverage와 별도로 출처 품질이 미해결된 후보 기간이다. 신호 관련 결론을 유보한다. gap ffill이나 임의 날짜 삭제는 하지 않았다.
- 제공자 논문 DOI 10.3390/data11040068은 정상 접근과 예약 재시도에서 HTTP 429/403으로 직접 읽지 못했다. 고정 v1.1 스키마·메타데이터·예제는 확인했지만 논문의 정밀도/결측 설명과의 일치 여부는 UNKNOWN이다. 밀리초 저장 단위를 측정 정밀도로 해석하지 않는다.
- 기존 10만 이벤트 AI 표본은 새 전체 집계와 분모를 섞지 않는다. 정적 크기 특성의 중심 간 분리 기여 97.88%는 정확도나 위험 설명률이 아니다. 추가 효익은 미입증이며 재학습은 하지 않았다.
- 기존 자동 수치검토 8,699건은 재사용한다. 사람 정답 검수와 독립 기하학 검증은 미수행이며 정답 정확도는 null이다. 이번에 기존 실제 baseline 전체를 재현한 것으로 표시하지 않는다.
- 일반 ChatGPT 원격 읽기 성공은 사용자의 전달 확인이다. 이 에이전트가 일반 ChatGPT에서 호출한 결과가 아니다. PRIVATE 저장소의 심사자 열람은 별도 사용자 승인과 실제 대상 계정 접근 확인이 필요하다.
- 공식 HWP 본문에서 PDF, 본문 약 5쪽, 코드 링크와 본선 실행 코드 조건을 직접 확인했다. 정확한 마감시각·개인 참가자격·자료의 공모 및 공개 이용 적합성은 별도 확인이 남아 있다. 공모전 본문·신청서·발표자료·제출은 작성하거나 수행하지 않았다.
