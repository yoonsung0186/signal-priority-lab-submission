## Scope of the calculations

A retains all valid nonnegative recorded PET events. B restricts them to PET
at most 5 s. C chooses the chronologically first signed-valid interaction per
scenario and ordered object pair, using earliest of four event timestamps,
then numeric event ID and event key; its nonnegative subset is the fraction
denominator. Negative representatives are counted and never replaced by later
positive ones. D filters the chosen C representatives to 0–5 s. These are
descriptive sensitivity populations, not corrections to the provider data.
Multiple conflict locations can make one representative per pair inappropriate;
spatial multiplicity is a diagnostic, not verified geometry. A remains primary.

Thresholds are 0.5, 1, 1.5 and 2 s. Null denominators stay null. Local dates use
Europe/Vienna, not a fixed UTC offset. Monthly/leave-one-month comparisons keep
the globally chosen representatives fixed. Date bootstrap B=200 and seed
20261012 use the same sampled date indices across scenarios and populations.
Dates are resampling clusters, not proven independent population observations.
Ranks are exploratory, with ties and insufficient support recorded.

Signal timestamps remain fixed. Event-only offsets shift all four event times
by the same delta, preserving PET, event key and population. The original
±0.5/±0.2/0 s and additional ±1/±2 s are stress conditions, not a measured error
distribution or guaranteed tolerance. Each role's state is sampled at its own
conflict-area entry time; the pair is not necessarily simultaneous and cannot
establish stop-line violations. Coverage uses half-open intervals, explicit
unknown/overlap/gap handling and local-date boundaries including DST.
Unresolved source quality periods are withheld from signal-related conclusions.

The previous automated numeric audit of 8,699 events is reused as such, not
human ground truth or independent trajectory geometry validation. Independent
accuracy remains null. Static dimensions' 97.88% centroid-separation share is
neither accuracy nor risk explained. The frozen 100,000-event AI sample is a
separate cohort; extra benefit remains unestablished. No refitting is allowed.

## Reproduction

Use the recorded Python environment and `requirements-r2.lock` in a project-local
environment. Obtain the licensed fixed SIT-PET v1.1 archives and the preserved
baseline artifacts at their recorded paths and hashes. No raw data or cache is
distributed in the source ZIP. Without them the real R2 replay is unavailable;
the source ZIP alone supports software tests, not an evidence-equivalent run.

Run `.venv/Scripts/python.exe tools/r2_postprocess.py --out runs/<fresh_R2_id>`
twice with unchanged `configs/r2_postprocess.json`. Compare every canonical
artifact hash. Do not run `finish_verify.py`: it reserves 22 new fits, while only
12 remain under the original cumulative cap. R2's allowed new fit count is zero.
The original baseline was replayed previously, not recomputed end-to-end in R2.

No contest report, application, presentation, policy narrative, public repository
conversion, invitation or actual submission is generated by this supplement.
